Contexto: talleres optativos de UTU

La UTU ofrece talleres optativos para estudiantes. Cada estudiante puede inscribirse a un taller, pero el sistema debe controlar que los datos sean válidos, que el taller exista, que haya cupo disponible y que no se repita una inscripción.

Talleres y cupos: Robótica (5), Podcast (4), Diseño web (6), Ajedrez (8) y Fotografía (5).

Razoná los métodos como si pertenecieran a una clase InscripcionTallerService. No crees una aplicación completa: escribí solamente los métodos solicitados.

public class InscripcionTaller {
    private String estudiante;
    private String grupo;
    private String taller;
    private int edad;

    public InscripcionTaller(String estudiante, String grupo, String taller, int edad) {
        this.estudiante = estudiante;
        this.grupo = grupo;
        this.taller = taller;
        this.edad = edad;
    }

    public String getEstudiante() { return estudiante; }
    public String getGrupo() { return grupo; }
    public String getTaller() { return taller; }
    public int getEdad() { return edad; }
}
