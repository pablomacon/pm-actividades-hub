¿Quién puede cambiar los datos?

Observá qué ocurre cuando cualquier parte de un programa puede cambiar un dato.

Ingresá para comenzar

Usá tu cuenta Google habilitada para esta actividad.

Esperando inicio de sesión.

public class Jugador {

    String nombre;
    int goles;

    public void marcarGol() {
        goles++;
    }
}
Jugador jugador1 = new Jugador();

jugador1.nombre = "Lucía";
jugador1.goles = 0;

jugador1.marcarGol();
1. Pensá el resultado

Después de ejecutar marcarGol(), ¿cuánto vale goles?

jugador1.goles = -300;
2. Acceso directo

¿Java permite hacer esto con la clase tal como está escrita?

¿Tiene sentido que un jugador tenga -300 goles?

El método marcarGol() controla cómo aumentan los goles, pero otra parte del programa puede modificar goles directamente y colocar cualquier valor.
